# 문항 구성과 출처

## 세 가지 학습 자료

- **1회차**: 사용자가 제공한 TOPCIT ESSENCE ver.3 6권과 2020 문제·해설 자료의 개념을 재구성하고 보강한 75문항. 원본 문항 전체를 그대로 옮긴 회차가 아니다.
- **2–10회차**: 같은 학습 범위에 기반한 창작 예상문제. 실제 출제된 기출문제라는 표시를 사용하지 않는다.
- **공식 문항 복습**: 사용자가 제공한 공식 시뮬레이션 화면에서 확인한 문항만 별도로 수록한다. 화면에는 실제 수록 수를 표시한다. 해설은 이 프로젝트에서 작성했으며 공식 정답 해설로 주장하지 않는다. 전체 공식 시뮬레이션은 별도 원본 링크로 연다.

TOPCIT은 이 프로젝트와 별개이며 시험의 출제·평가 주체가 아니다. 연습 점수는 공식 성적 예측값이 아니다.

## 회차 배분

| 영역 | 객관식 | 서술형 | 수행형 | 통합형 | 문항 | 배점 |

| 소프트웨어 개발 | 15 | 2 | 3 | 1 | 21 | 365 |
| 데이터 관리 | 15 | 2 | 1 | 1 | 19 | 265 |

객관식 5점, 서술형 30점, 수행형 50점, 통합형 80점. 수행형은 코드·도식·계산 등으로 표현된다. 모의시험은 150분이며 브라우저를 닫아도 저장된 마감 시각은 그대로 유지된다. 과거 화면의 긴 연습용 시간 표시는 시험 제한 시간으로 사용하지 않는다.

## 검수와 정정

문항의 ID·회차 배분·배점·정답 ID·보기별 해설·루브릭 합·도식 연결·중복 지문·출처 누락은 검증 스크립트로 검사한다. 개념이나 숫자가 같은 변형 문제는 있을 수 있으나, 원문 전체 지문을 복제해 문항 수를 늘리지 않는다. 서술형은 유일한 문장 답을 강제하지 않으며 루브릭으로 대안 표현을 인정한다.

모든 해설은 학습 자료이며 오류 제보 시 문제 ID와 이유를 기준으로 수정한다. 특히 오래된 해설에서 버전 의존 동작이나 잘못된 예외 설명을 그대로 답으로 사용하지 않는다. 확인한 정정 내용은 관련 source-review 문서에 남긴다.

문항별 `sources`는 책·장·확인한 PDF 페이지 또는 공공 웹 문서로 연결한다. 페이지 범위를 직접 확인하지 못한 개념은 장 수준으로만 표시한다. 원본 PDF와 개인 파일 경로는 저장소에 포함하지 않는다.
