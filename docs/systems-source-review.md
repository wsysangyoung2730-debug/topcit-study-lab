# 시스템·보안 출처 검토

이 문제은행은 학습용 재구성·창작 문항이다. 2020 자료의 파일명은 자료 식별용이며, 실제 시행 회차가 확인된 공식 기출이라는 의미가 아니다. 1회차는 제공 문제·해설과 ESSENCE의 개념을 재구성하고, 2~10회차는 해당 학습 범위를 바탕으로 새 사례를 작성한다. 원문 PDF와 스크린샷은 저장소에 포함하지 않는다.

## 확인 자료와 쪽수

- `2020 TOPCIT 문제풀이 03 시스템 아키텍쳐.pdf`: PDF 1~3쪽. RISC/RPO, TCP socket/OpenMP, SIMD 서술 문제.
- `2020 TOPCIT 문제풀이 03 시스템 아키텍쳐 해설.pdf`: PDF 1~3쪽. 문제와 해설 전체를 이미지로 대조했다.
- `2020 TOPCIT 문제풀이 04 정보보안 이해와 활용.pdf`: PDF 1~3쪽. IoT 위협/랜섬웨어, 무선랜/망분리, Java 시큐어 코딩 문제.
- `2020 TOPCIT 문제풀이 04 정보보안 이해와 활용 해설.pdf`: PDF 1~9쪽. 문제와 해설 전체를 이미지로 대조했다.
- TOPCIT ESSENCE ver.3 M3 `시스템아키텍처 이해와 활용` 및 M4 `정보보안 이해와 활용`: 문항의 장과 **책에 인쇄된 쪽수**를 출처로 사용한다. 제공 PDF에서 인쇄 쪽수보다 PDF 페이지 번호가 2 크다. 목차뿐 아니라 관련 본문도 확인했다.

## Java File 해설 교정

보안 문제 PDF 3쪽 및 해설 PDF 8~9쪽은 `new File(...)`과 `delete()`를 다루면서, 존재하지 않는 파일의 `File` 참조가 null이 되어 예외가 발생하고 `file != null` 검사로 이를 방지한다는 취지로 설명한다. 이 부분은 정답 근거로 사용하지 않는다.

Oracle Java SE 8 API의 [File 명세](https://docs.oracle.com/javase/8/docs/api/java/io/File.html)를 확인했다. `File` 객체는 파일·디렉터리 경로를 표현하며 실제 대상이 없어도 생성된다. `exists()`는 대상 존재 여부를 검사하고, `delete()`는 삭제 성공 여부를 boolean으로 반환한다. 따라서 객체 null 검사와 파일 존재 확인을 구분하고 삭제 실패도 처리해야 한다.

재구성 수행 문항은 외부 입력의 경로 결합 위험을 설명하고, 서버가 관리하는 허용 목록의 식별자를 실제 경로에 매핑한 다음 삭제 결과를 확인하도록 한다. 허용 목록 디렉터리와 파일을 공격자가 변경할 수 없다는 전제를 명시했다. null 검사는 목록 조회 실패 확인에만 쓴다. 원문의 슬래시 제거만으로 모든 운영체제·인코딩·심볼릭 링크·경합 위험을 해결한다고 주장하지 않는다.

## RISC·병렬 실행 표현 교정

시스템 해설 PDF 1쪽의 전통적인 RISC/CISC 비교는 입문용 모델이다. 특정 계열의 모든 명령이 반드시 한 클록에 끝난다거나, RISC는 반드시 Harvard 구조이고 CISC는 반드시 von Neumann 구조라는 단정은 새 문항에 사용하지 않는다. 문항은 단순한 명령 형식·파이프라인 설계에 유리한 특성과, 전통적인 하드와이어드 제어의 비교를 묻는다.

OpenMP 문항은 출력에 실제 나타난 스레드 ID 집합으로 참여 스레드 수를 구한다. 반복 횟수가 스레드 수라는 오개념을 설명하며, 실행 순서나 스레드별 작업 분배가 항상 동일하다고 가정하지 않는다.

ESSENCE M3 인쇄 54쪽의 스케줄링 표는 SRT를 비선점형으로 표시하지만, 새 문항은 남은 실행 시간이 더 짧은 작업이 도착하면 실행 중인 작업을 선점하는 SRT의 동작으로 설명한다. 선점하지 않는 SJF와 구분하여 표의 분류 오류를 답안에 옮기지 않는다.

## 채점과 편집 기준

객관식만 정답 ID로 채점한다. 서술·코드·다이어그램과 통합형의 자유 응답은 모범답안 및 배점 루브릭을 제공하는 자기 평가용이다. 통합형 소문항 배점 합계는 80점이다. 객관식은 선택지 네 개 각각의 개념과 해당 사례에 맞거나 맞지 않는 이유를 제공한다. 생성 순서에 따른 답 위치 편향을 막기 위해 선택지 순서를 결정적으로 회전한다.

법률의 현행 조문이나 연도에 따라 바뀌는 표준 순위는 문제화하지 않는다. 보안 원칙·암호의 역할·통제 설계·장애 복구처럼 제공 교재에서 확인되는 개념을 중심으로 학습한다.
