# 출시 검증 기록

검증일: 2026-10-09

## 자동 검사

- `npm run validate`: 연습 750문항 + 제공된 공식 캡처 24문항, 회차별 75문항·1,000점, 영역 배분, 고유 ID, 정답 키, 모든 보기 해설, 배점·루브릭 합, 출처, 도식 연결을 검사한다.
- `npm test`: 채점·단답 정규화·시험 제출·세션 분리·통합형 오답·재풀이 이력·최신 확인 시각·백업 검증·무작위 섞기 14개 테스트 통과.
- `npm run build`: TypeScript와 Vite 프로덕션 빌드 통과.
- 독립 저장소 검토에서 기존 기록 형식, 최신 체크포인트 복원, 오래된 저장이 새 체크포인트를 지우지 않는 경우를 확인했다.

## 실제 브라우저 검사

- 홈에서 10회차·750문항과 공식 내부 복습 24문항이 구분되어 표시됨.
- 객관식 오답 선택 → 정답 확인 → 정오 표시·모든 보기의 해설·학습 근거 표시.
- 답안을 선택한 직후 새로고침 → 같은 회차를 이어 열어 위치와 미확인 답안 복원.
- UML 시작·활동 노드 추가, 텍스트 편집, 흐름 연결, 모범 그림 표시 및 자기 평가 체크.
- 통합 문제 첫 소문항 확인 후 다른 소문항으로 전환했을 때 미확인 답안 비공개.
- 150분 시험에서 확인 버튼·해설 비공개, 제출 확인에서 미채점 점수 비공개, 제출 후 채점 및 답안 잠금.
- 오답·북마크 목록, 데이터 영역의 정규화 개념 필터 → 조건에 맞는 10문항 무작위 연습.
- 공식 캡처 OAuth 문항의 내부 정답 확인 및 인증/권한 위임 구분 설명.
- 모바일 390×844에서 가로 넘침 없음, 메뉴 열기와 학습실 복귀, 문제·보기·해설의 세로 배치 확인. 검사 후 화면 크기 복원.
- JSON 백업 다운로드 파일 생성 및 가져오기 성공 메시지 확인.
- 검증 중 브라우저 콘솔 오류·경고 없음.

## 검증의 범위

구조 검증은 모든 문항을 대상으로 한다. 내용은 영역별 자료와 계산·코드 예제를 검토했으나 독립된 공식 감수나 실제 시험 성적 예측을 의미하지 않는다. Python 예제와 주요 계산은 실행 검증했다. Java 예제는 JDK 미설치로 코드 검토만 수행했다. 자유 형식 답안에는 자동으로 정오나 AI 점수를 부여하지 않는다.

공식 내부 회차는 사용자가 제공한 화면에서 확인한 24문항이다. 공식 75문항 전체는 원본 실행 링크를 이용한다. 저장 기록은 기기·브라우저별이며 서버 동기화 기능은 없다.
