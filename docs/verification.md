## 검증의 범위

구조 검증은 모든 문항을 대상으로 한다. 내용은 영역별 자료와 계산·코드 예제를 검토했으나 독립된 공식 감수나 실제 시험 성적 예측을 의미하지 않는다. Python 예제와 주요 계산은 실행 검증했다. Java 예제는 JDK 미설치로 코드 검토만 수행했다. 자유 형식 답안에는 자동으로 정오나 AI 점수를 부여하지 않는다.

공개 기반 내부 회차는 제공된 24문항과 자체 재구성 51문항을 합친 학습 자료이다. 공식 원문은 별도 실행 링크를 이용한다. 저장 기록은 기기·브라우저별이며 서버 동기화 기능은 없다.

## 공식형 UI 교체

- 파란 상단, 왼쪽 문항 목록·진행 표, 문항 번호/배점, 문제/답안 영역 및 고정 하단 탐색 버튼을 실제 브라우저에서 확인했다.
- 학습 이어가기와 시험 모드의 시간·해설 공개 상태, 마지막 문항의 다음 버튼 비활성화를 확인했다.
- 문항별 해설·평가 기준·답안 작성 제목을 유지한다.

## 문제·답안 영역 높이 조절

- 손잡이 드래그로 51%에서 30%로 변경하고 다음 문항에서도 30% 유지 확인.
- 방향키로 높이 조절, 문제와 답안 별도 스크롤 지원.
- 390×844에서 가로 넘침 없이 보기·정답 확인·하단 탐색 버튼 표시 확인.
- 프로덕션 빌드 통과.

## 교재 개념 정리

- 개념 검색 → 비교표와 SVG 도식 열람 → 관련 문제 → 정답 확인 → 관련 개념 복귀의 전체 동선을 실제 브라우저에서 확인했다.
- 독립 코드 검토에서 새 개념 학습이 기존 답안을 덮어쓰지 않고, 시험 제출 전 개념·해설 버튼이 숨겨지는 조건을 확인했다.
- 소프트웨어/데이터 도식의 탐색 순서·UML 관계 방향·정규화 전제·ACID 표현을 별도로 검토했다.

## 공개 기반 75문항 확장 (2026-10-10)

- 인계받은 소스의 11개 파일을 변경 전 원본과 바이트 단위로 대조했다. 기존 24문항의 ID·지문·정답·루브릭·도식은 출시 데이터와 비교해 유지됨을 확인했다. 의도한 차이는 원문 번호/출처 안내와 74번의 비즈니스 영역 분류뿐이다.
- 재구성 51문항의 지문, 정답 근거, 모든 보기 해설과 자유 답안 루브릭을 읽고 검토했다. SQLite 모범 SQL의 실제 조회 결과·기본키/NULL 제약과 JSON 자료형을 테스트로 검증했다. Java/JDBC는 코드 검토 범위이며 임의 제출 답안을 실행하거나 자동 점수로 표시하지 않는다.
- 기존 24문항 세션 재개 시 `23 / 24`로 남는 문제를 Chromium에서 재현했다. 복원 및 백업 가져오기에서 진행 중인 공개 학습만 75문항으로 확장하도록 수정한 뒤, 같은 Robot 문항이 `3 / 75`로 열리고 답안·평가·확인 이력·북마크가 보존됨을 확인했다. 완료 기록, 시험, 복습 및 다른 회차는 변경하지 않는다.
- Chromium 브라우저 회귀 5개 통과: 신규 75문항 진입과 보기별 해설, 22·41번 통합형 하위 문항 전환, 미확인 해설 비공개, ERD 작성·예시 도식·자기 평가, 통합 출처의 자체 작성 안내, 150분 시험 이어 풀기·제출 전 해설/점수 비공개·제출 후 잠금·시간 만료 자동 제출.
- 390×844 모바일에서 백업 가져오기, 메뉴, 75문항 탐색과 마지막 문항의 다음 버튼 비활성화를 확인했다. 가로 넘침은 없었고 데스크톱과 모바일 화면을 시각적으로 확인했다.
- 프로덕션 빌드는 통과한다. Vite의 500kB 초과 번들 경고는 남아 있으며, 이 작업에서 범위 밖의 번들 분할은 하지 않았다.

브라우저 회귀 재실행은 별도 터미널에서 `npm run dev -- --port 4281 --strictPort`를 실행한 뒤 `npx playwright test tests/official-flow.spec.ts --workers=1`을 사용한다. Chromium이 설치되지 않았다면 `npx playwright install chromium`이 필요하다. 사용자 기록이 아닌 테스트 전용 브라우저와 합성 백업 데이터를 사용한다.
