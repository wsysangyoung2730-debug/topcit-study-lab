# 공개 시뮬레이션 기반 학습 기록

공식 원문은 [TOPCIT 시뮬레이션](https://www.topcit.or.kr/ibtsimulation/IBT.do)에서 실행한다. 내부 학습 세트는 사용자 제공 24문항과 공개 출제 개념을 참고해 새로 작성한 51문항을 합친 75문항이다. 공식 원문 전체 복사본이나 공식 정답집이 아니다. 해설은 이 프로젝트에서 작성했다.

2026-10-10 공개 화면이 사용하는 문항 목록과 일반 GET 응답을 읽어 75개 번호·유형·배점을 확인했다. 인증 우회나 비공개 정답 접근은 하지 않았다. 공개 응답에는 정답·해설이 없으며 빈 응시 답안 필드를 정답으로 간주하지 않았다. 원본 JSON과 이미지는 배포하지 않는다.

전체 75문항·1000점이며 객관식 60개, 통합형 3개, 수행형 5개(코드 4/UML 1), 서술형 7개다. 영역별 수는 소프트웨어 21, 데이터 19, 시스템·보안 18, 비즈니스 17개다. 내부 점수는 공식 성적이나 예측값이 아니다.

## 추가한 51문항

번호 1·2·8·10~24·26~48·51~57·59·68·73에 대응한다. 같은 개념과 유형을 연습할 수 있도록 사례, 수치, 지문, 선택지, 코드 등을 새로 작성했다. 문항 제목에 “공개 문항 N 기반 재구성”을 표시하고 출처에 자체 작성임을 밝힌다. 따라서 원문과 내부 문항의 정답 번호를 서로 대입하면 안 된다.

서술·코드·UML은 모범답안과 배점 기준을 제공하고 자기 평가한다. SQL은 명시한 방언 기준이며, 코드·쿼리의 임의 답안을 서버에서 실행하지 않는다. GPL 문항은 실행 파일 사본을 다운로드 배포하는 조건으로 구체화해 단순 원격 서비스와 혼동하지 않게 했다.

## 학습을 위한 보완 사항

- OAuth는 엄밀히 권한 부여·위임 체계라는 점을 해설에 명시했다. 인증 계층과 구별한다.
- 69번의 PERT 영문 풀이는 `Program Evaluation and Review Technique`, 72번의 ITIL 영문 풀이는 `Information Technology Infrastructure Library`로 바로잡고 해설에 알렸다.
- 75번은 국가법령정보센터의 [저작권법 제101조의2](https://law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=1017054983)를 2026-10-09 확인했다. 당시 본문은 시행 2026-08-11, 법률 제21336호다. 언어·규약·해법 자체와 구체적 프로그램 표현을 구분한다. 원문의 오픈소스 라이선스 보기는 오픈소스 역시 저작권과 라이선스 조건에 따라 이용한다는 취지로 설명했다.
- BFS는 왼쪽 인접 정점부터 처리한다는 순서를 명시했다. 그래프를 문자 그림과 간선 목록으로 함께 제공한다.
- 버블 정렬의 코드와 표기는 실행 가능한 Python 문법으로 정리했다. 제공 입력 및 빈 배열·단일 원소·역순·중복·음수·기정렬 사례를 실행해 결과를 확인했다.
- Java Thread의 대기는 수집 처리 뒤 10초를 쉬는 구조다. 정확한 고정 주기 수집을 보장한다는 설명을 피했다. `start()`와 `run()` 직접 호출을 구별하며, 원문 예외 처리의 반복 지속 동작도 설명했다.
- Robot 원문의 잘린 괄호와 CleanRobot 출력문의 빠진 세미콜론은 보완했다. `public` 클래스는 각각 별도 파일에 저장하는 예시임을 명시했다.
- CoffeeRobot의 `grab(int number)`는 부모의 `grab()`과 매개변수가 달라 오버로딩이다. 이를 오버라이딩으로 설명하거나 `@Override`를 붙이지 않았다.
- Person의 `Car` 필드 참조는 연관 관계로 표시했다. 외부 객체를 생성자에 전달하는 것만으로 집합 관계를 강제하지 않는다. 전체·부분이라는 추가 의미를 명시한 집합 모델은 허용하고, 합성의 수명주기 소유는 가정하지 않는다.

## 검증 범위

TypeScript 타입, 문항 수·ID 중복, round/origin/source, 객관식 정답 키와 보기 4개, 하위 문항 배점 및 루브릭 합계, UML 노드·연결 참조를 검증했다. 버블 정렬 모범답안은 Python으로 실행했다. 로컬에 Java 실행 환경이 없어 Java 모범답안은 컴파일하지 못했으며 선언·시그니처·제어 흐름을 검토했다. 임의의 코드·서술·UML 응답을 자동 채점했다는 의미는 아니다.
