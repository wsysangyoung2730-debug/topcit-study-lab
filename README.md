# TOPCIT Study Lab

문제마다 이해를 쌓는 TOPCIT 학습 사이트. 교재와 제공된 문제·해설의 형식을 참고한 1회차, 개념을 확장한 창작 2~10회차를 제공한다. 공식 TOPCIT 서비스나 공식 기출 전체 복원본이 아니다.

## 실행

Node.js 22.12 이상에서 `npm ci`, `npm run dev`를 실행한다. 배포 파일은 `npm run build`로 만든다.

## 개발

GitHub 이슈 → 별도 작업 브랜치 → 세부 커밋 → develop 병합 확인 → develop 대상 PR 순서로 작업한다. 세부 규칙은 AGENTS.md를 따른다.

## 콘텐츠

교재 기반 창작 문항과 참고자료 기반 재구성 문항을 구분한다. 원본 PDF는 공개하지 않으며 문제별 근거의 자료명·장·페이지를 기록한다. 서술·코드·UML은 모범답안과 자기 평가 기준을 제공한다.
