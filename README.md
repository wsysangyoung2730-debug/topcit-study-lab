# TOPCIT Study Lab

문제를 풀고, **정답과 모든 보기의 해설을 함께 읽는** TOPCIT 개인 학습 사이트입니다.

[사이트 열기](https://topcit-study-lab.vercel.app/) · [문항 구성과 출처](docs/content-policy.md)

## 학습 기능

- 10회차 × 75문항: 1회차 자료 재구성, 2–10회차 창작 예상문제
- 학습 모드: 문제마다 정답 확인 → 풀이·오답 보기·관련 개념·출처
- 모의시험: 150분, 제출 전 해설 비공개, 자동 제출과 이어 풀기
- 무작위 연습: 영역·개념 필터와 문제 수 선택
- 오답·북마크, 최근 답안 기준 통계, 학습 세션별 기록
- 코드/SQL 답안 작성, UML 도형·관계선 편집, SVG 저장 및 예시 도식 비교
- 브라우저 내 자동 저장, JSON 백업 내보내기·가져오기
- 공식 원본 링크와 사용자 제공 공식 캡처 문항 복습을 별도 제공

객관식과 허용 답안이 정의된 단답형은 자동 채점합니다. 서술·코드·도식은 **모범답안과 기준을 보고 자기 평가**합니다. 서버에서 코드를 실행하거나 AI 점수를 생성하지 않습니다. 답안과 해설은 정적 파일에 포함되므로 감독 시험용 보안 시스템이 아닙니다.

## 실행

Node.js 24 이상을 사용합니다.

```sh
npm ci
npm run dev
```

```sh
npm run validate
npm test
npm run build
npm run preview
```

## 구성

- `src/content/`: 영역별 문항, 공식 캡처 회차, 회차 설명
- `src/components/`: 답안 입력·해설·UML 편집
- `src/lib/`: 채점, 학습 세션, IndexedDB 기록
- `scripts/validate-content.ts`: 750문항의 구조와 회차 배점 검증
- `tests/`: 채점·기록·무작위 출제의 회귀 검증
- `.github/workflows/`: PR 및 main·develop의 자동 검증

새 문항은 `src/types.ts`의 `Question` 구조를 따릅니다. 객관식은 네 보기 각각의 설명이 필요하며, 자유 답안은 모범답안과 배점 합이 일치하는 평가 기준을 포함합니다. 통합형은 하위 문항 합을 검증합니다.

## Vercel 배포

Vite 프리셋을 사용하며 `vercel.json`에서 문항 검증 → 회귀 테스트 → 빌드를 순서대로 수행합니다. 출력 폴더는 `dist`입니다. GitHub 저장소의 `main`을 프로덕션 브랜치로 사용합니다. `.vercel`의 로컬 프로젝트 정보와 환경 파일은 저장소에 포함하지 않습니다.

## 기록 보관

기록은 해당 브라우저·사이트 주소의 IndexedDB에 저장됩니다. 기기 간 자동 동기화는 제공하지 않습니다. 브라우저 데이터를 삭제하기 전 또는 기기를 옮기기 전에 백업을 내보내세요. 가져오기는 현재 기록을 교체하기 전에 확인을 표시하며 잘못된 파일은 거부합니다. 서버로 학습 기록을 전송하지 않습니다.

## 개발 규칙

`main`은 출시, `develop`은 개발 통합 브랜치입니다. 이슈 생성 후 `태그/#번호-작업범위` 브랜치에서 작업하며 최신 develop을 병합해 확인한 뒤 develop 대상 PR을 만듭니다. 커밋은 `[소문자태그] 한글 명령조`로 50자 이내에 작성합니다. 상세 규칙은 [AGENTS.md](AGENTS.md)를 참고하세요.

이 프로젝트는 TOPCIT 공식 서비스가 아닙니다. 원본 교재·제공 문항의 권리는 해당 권리자에게 있으며, 원본 PDF를 재배포하지 않습니다.
